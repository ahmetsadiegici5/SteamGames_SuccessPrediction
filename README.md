# Steam Games Success Prediction

A machine learning project that analyzes Steam game data and predicts whether a game will be successful based on its features.

## Models

The project compares four classification models:

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Technologies

- Python
- Pandas & NumPy
- Scikit-learn
- XGBoost
- Matplotlib & Seaborn
- Streamlit

## Project Structure

`
data/
    steam.csv
Phase3_Final_Project.ipynb
streamlit_app.py
requirements.txt
README.md
`

## Run the Project

Install the required packages:

`
pip install -r requirements.txt
`

Run the Streamlit application:

`
python -m streamlit run streamlit_app.py
`

The notebook contains the data analysis, preprocessing, model training, and evaluation steps.
